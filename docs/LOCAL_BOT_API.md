# Точка расширения: Local Telegram Bot API

**Не реализовано в UI 0.1.0.** Текущая версия использует только `https://api.telegram.org`, с hosted download limit 20 MB. Этот документ — архитектурный план расширения, не инструкция включить несуществующий переключатель.

Официальный локальный сервер: <https://github.com/tdlib/telegram-bot-api>. Документация: <https://core.telegram.org/bots/api#using-a-local-bot-api-server>.

Local Bot API способен предоставлять скачивание без hosted-лимита и возвращать абсолютный local `file_path`. Это требует отдельной установки/обслуживания сервера, `api_id`/`api_hash` и соблюдения официального процесса миграции бота (в том числе `logOut`, если требуется). TeleDrop не разворачивает сервер, Docker или VPS и не выполняет миграцию автоматически.

## Что потребуется изменить

1. Добавить явную настройку `hosted | local`, адрес сервера и UI с предупреждением о дополнительных зависимостях.
2. Ввести `TelegramEndpoint` вместо фиксированного `Telegram.base` в `src-tauri/src/telegram/mod.rs`. Поддержка адресов только после проверки scheme, host и доверенной модели подключения; нельзя случайно отправить токен на arbitrary frontend URL.
3. Убрать `HOSTED_LIMIT` только для проверенного local mode. Hosted mode должен сохранить предупреждение и лимит.
4. Разделить источник файла: hosted HTTP stream и проверенная local path source. Абсолютный путь от сервера не должен трактоваться как unrestricted local filesystem access. Если сервер на другой машине, его путь не является путём этого Windows-компьютера.
5. Сохранить destination streaming, bounded concurrency, cancellation, hash-based finalization и no-clobber Windows move.
6. Пересмотреть byte-size типы, большие очереди, свободное место, shutdown и UI для длительных загрузок.
7. Добавить автоматические тесты обоих режимов и реальные большие файлы. Не объявлять byte-level resume, пока HTTP Range или эквивалент не реализован и проверен.

По умолчанию лучше loopback или отдельно защищённый доверенный сервер. Удалённый сервер становится участником доверенной цепочки: он видит токен и медиа. Несекретный endpoint хранится отдельно от секретов; URLs и ошибки по-прежнему редактируются перед логированием.

Эта опция увеличивает возможности, но ухудшает простоту установки и требует администрирования. Для фото и коротких видео рекомендуем hosted mode.
