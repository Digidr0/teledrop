# Ручная проверка с настоящим ботом

Нужен тестовый бот @BotFather, Windows 11 и папка с правом записи. **Не помещайте реальный токен в этот файл, команды shell, screenshots или Git.** Автоматические тесты не являются доказательством реальной доставки Telegram.

## Первый запуск

- [ ] Запустить installer, затем установленный TeleDrop.
- [ ] Проверить portable на машине с WebView2; отсутствие runtime должно быть документировано, а не скрыто.
- [ ] Нативная рамка, maximize/resize, минимум 840×600, масштаб Windows 100/125/150%.
- [ ] Без токена: «Не настроен», нет фиктивных загрузок и Connected.
- [ ] Проверить invalid token: секрет не показывается в тексте ошибки.
- [ ] Ввести настоящий токен только в password field; проверить getMe, очищение поля и Credential Manager.
- [ ] Выбрать папку с кириллицей через настоящий диалог и сохранить настройки.
- [ ] Подключиться; дождаться успешного polling и статуса «Подключён».

## Получение и запись

- [ ] Отправить фото; проверить файл максимального доступного разрешения.
- [ ] Отправить короткое видео и видео как документ; оба файла открываются в Windows.
- [ ] Отправить mixed album; все поддерживаемые файлы приняты, без обещания атомарного альбома.
- [ ] Отправить поддерживаемый файл около лимита и видео >20 MB; большой файл отмечается ошибкой, не Completed.
- [ ] Неподдерживаемый документ не скачивается.
- [ ] Подпапки Photos / Videos работают только при включённой настройке.
- [ ] Реальные downloaded bytes, скорость и percentage соответствуют known size. Unknown size — без выдуманного percentage.
- [ ] Существующий одноимённый файл не меняется; следующий получает суффикс.
- [ ] Проверить имя с Unicode, Windows reserved names и символами путей; файл остаётся в назначенной папке.
- [ ] «Открыть файл», «Показать в Проводнике», «Открыть папку» работают; удалённый извне файл выдаёт ошибку.
- [ ] Разные значения concurrency не запускают более выбранного количества новых workers.

## Повторы и восстановление

- [ ] При skip duplicates повторная отправка того же файла не создаёт второй download.
- [ ] При выключенном skip duplicates новая отправка создаёт отдельный файл без перезаписи.
- [ ] Отменить queued и downloading задания; проверить Cancelled, отсутствие неполного final file.
- [ ] Retry failed/cancelled возвращает задание в очередь; без подключения queued не становится fake downloading.
- [ ] Отключить интернет: Connected меняется, включается reconnect/backoff; восстановить сеть и получить настоящий новый файл.
- [ ] Закрыть приложение во время загрузки: процесс завершается, очередь сохраняется, при следующем подключении файл начинается с начала.
- [ ] На отдельном тестовом профиле завершить процесс принудительно во время `.part` и финализации. После запуска сверка состояния не создаёт silent overwrite.
- [ ] Заблокировать папку, отсоединить внешний диск или вызвать недостаток места на специально подготовленном тестовом диске. Не заполняйте системный диск ради теста.
- [ ] Проверить persisted history, поиск, фильтры и пагинацию после перезапуска.
- [ ] Другой poller/webhook вызывает явный конфликт; webhook не удаляется, pending updates не сбрасываются.
- [ ] Заменить токен на другой тестовый бот: offsets и задания не смешиваются. Удалить токен: workers останавливаются, Credential Manager entry удалён.

## UI, безопасность и Windows

- [ ] Light / Dark / System на всех страницах, tooltip, контекстных элементах и пустых состояниях.
- [ ] Смена системной темы Windows при System; после рестарта предпочтение остаётся System.
- [ ] Keyboard Tab/Shift+Tab, Enter, видимый focus; Windows reduced motion.
- [ ] Нативные уведомления у установленной версии, включая настройки уведомлений Windows. Dev/portable-уведомления могут иметь другое отображение/идентичность.
- [ ] Повторный запуск EXE поднимает уже открытое окно, не запускает второй polling engine.
- [ ] SQLite, логи, localStorage и profile files не содержат токен. Технические логи не содержат credential-bearing URLs.
- [ ] При разрешённых chat ID разрешённый чат скачивается, другой не создаёт задания.
- [ ] Закрытие означает выход, а не скрытую работу в трее. Windows autostart не включён.
- [ ] Обновление бинарника сохраняет настройки и историю.
