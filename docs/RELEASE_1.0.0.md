# TeleDrop 1.0.0

Windows 11 x64: скачивание фото и видео из Telegram через бота.

- Статистика вверху главной страницы.
- Проверка новых стабильных GitHub Releases при запуске и каждые 6 часов; кнопка новой версии под логотипом. Кнопка открывает релиз, не устанавливает обновление автоматически.
- Telegram API connectivity check, Light/Dark/System, история SQLite, очередь и потоковая запись файлов.
- Прокрутка внутри блоков загрузок и истории, реакция ⚡ после сохранения, Windows-уведомление на `/start`.
- Токен хранится в Windows Credential Manager, не входит в исходники или пакеты.

## Установка

Рекомендуется `TeleDrop_1.0.0_x64-setup.exe`. Portable ZIP или отдельный EXE требуют установленного Microsoft WebView2 Runtime. SHA-256 прилагаются.

Создайте бота через официальный @BotFather (`/newbot`), введите токен только в Настройки TeleDrop, выберите папку и подключитесь на Главной. Отправьте боту фото или видео.

## Ограничения

Hosted Bot API: до 20 MB; pending updates Telegram хранятся до 24 часов. После прерывания файл скачивается с начала. Трей, Windows autostart и Local Bot API не реализованы. Артефакты без подписи издателя. Реальный Telegram E2E и установка на чистой Windows остаются ручными проверками.

Сборка проверяет TypeScript/Svelte и компилирует Rust release. Полный набор тестов для этой версии не запускался по ранее согласованному пожеланию пользователя.
